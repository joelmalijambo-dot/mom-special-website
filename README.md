# 💞 Special Love For Mom 💞

A heartfelt website dedicated to celebrating the amazing woman who means everything to me.

## Features

✨ **Special Features:**
- 💌 Love Messages - Heartfelt messages expressing gratitude
- ✨ Inspirational Quotes - Beautiful quotes about mothers
- 💝 Dear Mom Letter - A personal letter of appreciation
- ❤️ Reasons Why Mom is Amazing - A list of wonderful qualities
- 🌟 Daily Affirmation - Random daily affirmations for mom
- 💗 Love Counter - Track and count expressions of love

## How to Use

1. Open `index.html` in your web browser
2. Browse through all the special sections
3. Click "Get Today's Affirmation" to receive a random uplifting message
4. Click "Add One More" to count your expressions of love (saved in your browser)

## Technologies Used

- HTML5
- CSS3 (with animations and gradients)
- Vanilla JavaScript
- LocalStorage (for persistent counter)

## Customization

You can easily customize this website:
- Edit the messages in `index.html`
- Add more affirmations in `script.js`
- Change colors and styling in `style.css`
- Add your own personal touches!
